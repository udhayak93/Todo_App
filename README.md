# Todo List App

A full-stack Todo List application built using the MERN stack.

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Features

- Add todos
- Edit todos
- Delete todos
- Mark todos as completed
- Store todos in MongoDB
- REST API using Express.js

## Project Structure

todo-list/
├── client/        # React frontend
└── server/        # Node.js + Express backend
